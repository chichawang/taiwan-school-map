# 全臺各縣市國中小學區地圖

一個免後端、可離線開啟的互動式單頁網頁應用（`index.html`），整合全臺 **22 個縣市** 的國民小學、國民中學學區範圍、村里界線、鄉鎮界線與校園位置。

## 功能特色

- **全臺 22 縣市涵蓋**：支援切換基隆市、臺北市、新北市、桃園市、新竹市、新竹縣、苗栗縣、臺中市、彰化縣、南投縣、雲林縣、嘉義市、嘉義縣、臺南市、高雄市、屏東縣、宜蘭縣、花蓮縣、臺東縣、澎湖縣、金門縣、連江縣。
- **國小 / 國中學制切換**：一鍵切換查詢國民小學或國民中學學區。
- **快速搜尋與篩選**：可依行政區篩選，或輸入學校名稱、村里名稱即時搜尋。
- **地圖圖層控制**：
  - **鄉鎮邊界**：開關各鄉鎮市區行政界線。
  - **鄰里邊界**：以正藍色線條顯示細緻的村里界線。
  - **顯示里名**：放大至 12 級以上時顯示村里名稱標籤。
  - **OSM 底圖**：可隨時切換疊加 OpenStreetMap 向量底圖（需網路連線；未開啟時仍可離線使用鄰近縣市鄉鎮底圖）。
- **選取範圍強化標示**：點選學校或村里後，會以粗紅框與高飽和度標示目標學區範圍，並淡化其餘區域，同時列出詳細的鄰別、共同／自由學區條件與教育局處公告連結。
- **Canvas 高效能渲染**：採用 Leaflet Canvas 渲染器與幾何簡化處理，確保大量村里多邊形下仍能流暢縮放與瀏覽。

## 使用方式

1. 下載本專案中的 `index.html`。
2. 直接使用現代瀏覽器（Chrome、Edge、Firefox、Safari 等）雙擊開啟即可使用，無須架設伺服器或安裝任何套件。
3. 若上傳至 GitHub 並開啟 **GitHub Pages**，即可直接透過網頁網址線上瀏覽。

## 資料來源與說明

- **村里與鄉鎮界線**：內政部國土測繪中心村里界圖（2026 年 8 月 17 日版）。
- **校園點位**：內政部國土測繪中心各級學校範圍圖及各縣市官方校址。
- **學區劃分資料**：
  - **桃園市、新北市、臺北市、新竹市、臺中市、高雄市**：採自各縣市政府教育局（處）公開學區資料與鄰里／門牌資料（桃園、新北部分分鄰範圍以公開門牌點位估算；臺北市套用官方鄰界圖）。
  - **其餘 16 縣市**：依國土測繪中心各級學校範圍圖與村里界線，以校園空間距離推估各村里所屬學區。
- **底圖**：OpenStreetMap（由 OpenFreeMap 提供）。
